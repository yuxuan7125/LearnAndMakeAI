# Learn and Make AI

## 介紹
**透過實作，學習AI背後的運作原理**

## 功能
- **訓練資料自動生成**
    - 加入隨機雜訊，使生成的資料與初始函數產生差異。
- **模型訓練**
    - 使用梯度下降法訓練模型
    - 使用 loss 評估模型預測的誤差
- **模型儲存與載入**
- **模型預測**
    - 將預測結果四捨五入取至整數位
- **模型評估**
    - 將資料分為訓練資料與測試資料
    - 計算測試資料的loss，評估模型的預測表現
- **多輸入與多次方的模型**
    - 運用清單設定輸入個數與多項式次數，方便調整模型


## 已知限制
- **訓練資料中不得包含判斷**
